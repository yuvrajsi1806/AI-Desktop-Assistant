# AI-Powered Desktop Assistant with Facial Recognition (JARVIS)

## Project Overview

An AI-powered desktop assistant developed using Python that combines facial recognition, voice commands, chatbot functionality, and desktop automation into a single application.

The project aims to provide an interactive, intelligent, and user-friendly desktop experience through voice-based interactions and facial recognition authentication.

## Key Features

- **Facial Recognition Authentication:** Recognizes registered users using computer vision techniques.
- **Voice Command Recognition:** Accepts voice instructions through a microphone.
- **Text-to-Speech:** Provides spoken responses to user queries.
- **AI Chatbot Integration:** Supports interactive conversations and user assistance.
- **Desktop Automation:** Performs tasks such as opening applications and executing system commands.
- **SQLite Database:** Supports local data storage and management.

## System Workflow

1. The user launches the desktop assistant.
2. The system uses facial recognition to authenticate the user.
3. After authentication, the assistant listens for voice commands.
4. The voice recognition module processes spoken instructions.
5. The assistant executes the corresponding task or processes the chatbot request.
6. The system provides feedback through voice or text.

## Project Modules

### 1. Facial Recognition Module
Uses OpenCV and face recognition technology to detect and recognize authorized users.

### 2. Voice Recognition Module
Converts spoken commands into text using the SpeechRecognition library.

### 3. Text-to-Speech Module
Generates voice responses using pyttsx3.

### 4. Chatbot Module
Processes user queries and provides conversational responses.

### 5. Desktop Automation Module
Executes supported desktop operations and application commands.

### 6. Database Module
Uses SQLite for local data storage and management.
